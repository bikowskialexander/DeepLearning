# DeepLearning

## Description
This repository contains a collection of scripts to train and record networks to complete tasks in the Gym/MuJoCo environment. There are tools to graph the progress of the training live and save the configuration of the model and hyperparameters automatically. The replay buffer, live result graphing, environment display, and networks are designed to be highly modular and minimize the difficulty in changing algorithms and hyperparameters, allowing for easier comparison and testing.
